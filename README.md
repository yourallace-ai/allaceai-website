# Allace AI | Official Static Marketing Website

This repository contains the standalone, production-ready static marketing website for **Allace.AI**.

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build production bundle
npm run build
```

---

## 🚀 Deployment Instructions

This project is a standard React + Vite SPA and can be deployed directly to any static host:

- **Vercel**: Connect repository -> Build command: `npm run build` -> Output dir: `dist`
- **Netlify**: Connect repository -> Build command: `npm run build` -> Publish dir: `dist`
- **Cloudflare Pages**: Connect repository -> Framework preset: `Vite` -> Output dir: `dist`
- **GitHub Pages**: Build `dist` and deploy using standard gh-pages action.
